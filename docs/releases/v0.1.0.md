# rust-mirror 0.1.0

Qualified release candidate: prepublication gates passed. Owner publication
authorization and official postpublication checks remain pending; there is no
published crate/tag/GitHub Release yet. The expanded user guide/reference changes
packaged documentation. Its [refreshed clean package audit](https://github.com/rustcommons/rust-mirror/blob/main/docs/evals/2026-11-11-user-documentation.md#documentation-complete-clean-package)
passed at `93f38921000ba4e8cc1d55006afd326c077d8f7e`; earlier native/server evidence retains
its original scope. Publication still requires the owner's go-ahead.

## Changes

- Add a complete [user guide](https://github.com/rustcommons/rust-mirror/blob/main/docs/USER-GUIDE.md)
  and [command/configuration reference](https://github.com/rustcommons/rust-mirror/blob/main/docs/CLI-REFERENCE.md),
  including Windows/Unix deployment, existing-client updates and recovery.

- Select explicit Rust toolchain versions/channels, Linux/Windows/macOS hosts,
  profiles, components and compilation targets; import project toolchain files.
- Freeze metadata before verified all-format downloads. Resume a saved run or use
  explicit destructive `--force` to replace its managed state without a backup.
- Assemble immutable retained generations, add pinned Rustup bootstrap/self-update
  endpoints and promote original dated stable/beta/nightly metadata explicitly.
- Publish from the native Rust CLI to fresh Nexus Raw prefixes over verified HTTPS,
  with private-CA/scoped Basic credentials, no-overwrite preflight and GET hashes.
- Supply a documented fixed Raw-group update workflow and repeatable native proof.

## Upgrade

This is the first release; there is no previous published rust-mirror schema or
installation to migrate. Rust/Cargo 1.90+ builds the CLI. Rustup installs clients;
client platform SDKs/linkers and trust configuration remain operator prerequisites.
Keep complete older generations for pinned clients. Mirror publication does not
silently change Nexus group membership or the client's environment.

## Validation and limits

Native lifecycle qualification passed on Linux/x86-64, Windows/x86-64 and both
macOS architectures, including default profiles and offline documentation. Actual
Nexus OSS selected/collection publication and fixed-URL updates passed. A fresh
unpacked locked package install passed native publication/client checks. The
[qualification record](https://github.com/rustcommons/rust-mirror/blob/main/docs/evals/2026-11-11-rustup-lifecycle.md)
records exact refs, hashes, actual results and failed setup attempts separately.
macOS headless CA-removal timeouts are recorded with private-key destruction and
fresh hosted-VM teardown; explicit removal is not falsely claimed. Official
registry installation, archive/docs.rs/tag/Release verification follow publication.

Scheduling, pruning, Cargo registry mirroring and GUI are excluded. Original
OpenPGP signatures are retained without independent signature verification.
Actual Nexus OSS qualification uses an isolated legacy compatibility fixture;
production policy/current Community Edition onboarding still needs an operator.
Only selected available modern Rustup artifacts are mirrored; missing explicit
requests refuse rather than silently shrinking. No OS SDK or arbitrary Cargo
project's offline dependency closure is supplied.
