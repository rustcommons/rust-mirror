# rust-mirror 0.1.1

Documentation-only CLI/library patch. Publication and verification are tracked in
[the release record](https://github.com/rustcommons/rust-mirror/blob/main/docs/evals/2026-11-11-docs-0.1.1.md).

## Changes

- Add a [docs.rs walkthrough](https://docs.rs/rust-mirror/0.1.1/rust_mirror/) for
  installation, platform/configuration selection, first generation, Nexus publishing,
  client setup, updates/recovery and Rust library examples.
- Describe exported API types, fields and operations, including effects, return
  values, validation boundaries and errors. Enable missing-documentation warnings.
- Organize the crates.io README into a practical quick start and documentation map.
  Remove the repository-rename/local-prototype paragraph.

## Upgrade

Install with `cargo install rust-mirror --version 0.1.1 --locked`.
Rust/Cargo 1.90 remains the build minimum. Runtime logic, API signatures, dependency
requirements/checksums and config/plan/inventory schemas are unchanged. No mirror
rebuild, client migration or Nexus change is required just for this docs patch.

## Validation and limits

The record separates new docs/package/install checks from retained 0.1.0
native/Nexus evidence. No broad runtime matrix is claimed as rerun for comments
or README changes. Platform/server, trust, SDK, Cargo-registry, scheduling,
pruning and GUI exclusions remain. Independent OpenPGP validation is not added.
