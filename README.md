# rustup-offline-mirror

Placeholder for a possible Rustup offline mirror project. The original description,
“Generate and serve complete offline mirrors for Rustup installations,” records an
idea, not implemented functionality or an approved functional requirement.
Naming and product scope remain undecided.

## Current state

This repository contains documentation, a license, and ignore rules. It has no
implementation, binaries, manifest, automated tests, or build workflow. Installation
prerequisites and setup commands are not defined. No compatibility guarantees are
established.

Windows-local prototypes and notes are outside this repository and have not been
reviewed for this documentation audit. They are not evidence of repository behavior.
